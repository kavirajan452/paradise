# Paradise Wire Recycling Industry Website

A modern, responsive React website for Paradise Wire Recycling Industry built with React 18, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Technology Stack

- **React 18** - Modern UI library
- **Vite** - Fast build tool and dev server
- **React Router** - Client-side routing
- **Tailwind CSS v4** - Utility-first CSS framework
- **Framer Motion** - Animation library
- **Swiper.js** - Modern slider library
- **React Icons** - Icon library

## 📦 Installation

```bash
npm install
```

## 🛠️ Development

Run the development server:

```bash
npm run dev
```

The site will be available at `http://localhost:5173`

## 🏗️ Build

Build for production:

```bash
npm run build
```

## 📝 Preview Production Build

```bash
npm run preview
```

## 🎨 Features

- ✅ Sticky header with navigation and mega menu
- ✅ Full-viewport hero section with animations
- ✅ Animated statistics counter on scroll
- ✅ Division cards with hover effects and mobile slider
- ✅ Products & Materials two-column layout
- ✅ Technology section with image grid
- ✅ Responsibility section with polaroid-style images
- ✅ Clients section with logo carousel
- ✅ Call-to-action section with contact cards
- ✅ Comprehensive footer
- ✅ Fully responsive design (mobile, tablet, desktop)
- ✅ Smooth scroll behavior
- ✅ Dark industrial theme with copper/orange accents

## 📱 Responsive Design

The website is fully responsive and optimized for:
- Mobile devices (320px+)
- Tablets (768px+)
- Desktops (1024px+)
